# DogHouse

## Public Provenance Register for SDCA-Governed Creative Works

This repository is the **public publication surface** for SDCA Position-3
Closure Records (legacy identifier `AWAP-W`) — public, redacted summaries
of the human-authorship and responsibility record for individual
published works, most immediately the `SubStack` article series
(`AI-Human-First_Architecture/11_Independent_Publishing/SubStack/`).

## What this is

Each published article gets one file here: `AWAP-PUBLIC-<slug>.md`. It
records the declared human genesis, the production mode, a summary of AI
involvement, and the Architect's signed Human Responsibility Statement —
so a reader can see, without needing repo access, that the piece has a
declared origin and a human standing behind it.

## Authority boundary

This public repository is **not the canonical AWAP and does not create
or extend authorship authority**. It publishes a redacted summary of a
closure record that already exists, in full, in the private canonical
repository.

```text
public AWAP presence          ⇏  authorship authority
publication in DogHouse       ⇏  AWAP closure (closure happens privately, first)
redacted public summary       ⇏  the complete internal record
```

The controlling closure record — full genesis declaration, iteration
log, process trail, CEA records, GIB/PSV state — remains in the private
canonical repository (`AI-Human-First_Architecture`, under
`11_Independent_Publishing/SubStack/02_articles/<article>/00_gates/`,
per `SDCA/03_Gates/AWAP/AWAP_Template_v1_0.md`). This repository
publishes only what `AWAP-PUBLIC-TEMPLATE.md` names as public fields.

## What is deliberately not published here

- Full iteration logs and session-level drafting mechanics
- Full CEA record text (existence and count are referenced, not
  reproduced)
- Process trail / Resonant log detail
- Internal GIB/PSV technical state
- Any pre-closure draft material

These stay in the private canonical repository. What is redacted and why
is stated explicitly in each `AWAP-PUBLIC-<slug>.md` file, not left
implicit.

## Materials

- `AWAP-PUBLIC-TEMPLATE.md` — the template each article's public AWAP is
  filed against.
- `PUBLIC-AWAP-REGISTER.md` — index of every public AWAP published here.
- `AWAP-PUBLIC-<slug>.md` — one per published article, added only once
  that article's internal AWAP has actually closed.
